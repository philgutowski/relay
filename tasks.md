Define the set of digest keys classify guarantees, alongside the other named contracts in `contracts.py` (near `HALT_LINES`), and add a test that fails if `run.py` or `closeout.py` reads a key not in that set, or if `classify.py` stops setting a key either module reads. This task adds a guard only; it must not change any runtime behavior. The full suite must stay green with the same test count plus the new one(s), and every existing test in `test_run.py`, `test_closeout.py`, and `test_classify.py` must still pass unchanged. - [x] T-2 The terminal record's `cli_version` field is always `contracts.CLI_VERSION_TESTED`, a pinned constant, never the version of the `claude` binary that actually ran. Read the real CLI version once per run (e.g. from `claude --version`, run through the same subprocess wrapper `launch.py` already uses, never a shell string) and record it in the terminal record alongside the pinned constant, so a version drift between the two is visible in `state.json` rather than silently invisible. Keep `CLI_VERSION_TESTED` as the pinned value Relay was tested against; add the observed value as a new field. Test with a fake `claude --version` output in the test harness, asserting both fields land in the terminal record and differ when the fake reports a different version. (c5b20a00ec39013b0a2417980930997d282252aa)

- [x] T-3 `comments_since` in the github and jira adapters returns every comment on the card when the baseline comment id is not found in the fetched list, rather than treating that as an unresolved baseline. A deleted or edited-away baseline comment currently makes `confirm_blocked_comment` read as satisfied even when the closeout wrote nothing new, because the full comment list is scanned as if the baseline were the very first comment. Change both adapters so a baseline id absent from the fetched comments is reported as unresolved rather than silently treated as "everything since the start," and add one test per adapter pinning the new behavior. Do not change the behavior when the baseline id is found or when no baseline was given. (f77468382e44552b0938ee920b15a50d11eafe77)
